Remote-SSH only connects when the VS Code you connect from and the Linux host run the same commit. Download that commit's files here, carry them over, and install them on the host.

Add your extensions

Paste your extensions.txt, or drop the file anywhere on this page. One publisher.name per line, # lines skipped. Each extension comes at its newest build that supports this version.

Download everything

Saves the four VS Code files and the extras tar, which holds the extensions and the checksums the host checks against. If your browser asks to allow multiple downloads, allow it.

    For scripts (MECM, SCCM, Intune)

    This page is static, so it cannot answer scripts. Microsoft's update server can: each URL below redirects to that exact release, so a deployment script can pin the version the hosts run. Swap the version for latest to follow the newest release.
